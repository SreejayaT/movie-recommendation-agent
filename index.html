A movie and series recommender that reads real reviews before it answers. Tell it what you feel like watching, and it suggests a title backed by review text, not just a star rating.

How it works

  1. You describe a moodType what you feel like watching. If the request is vague, the agent asks one clarifying question first.
  2. It searches critic reviewsYour request is embedded with all-MiniLM-L6-v2 and matched by cosine similarity against stored review embeddings. The top 6 reviews come back.
  3. It checks the detailsA tool call to OMDb fetches the year, runtime, genre, poster, and IMDb rating of the title it is considering.
  4. It answers with evidenceLlama 3.3 70B explains the pick using language from the reviews, says so when critics disagree, and lets you open the reviews it used.

Why reviews, not ratings

A 7.8 doesn’t say whether a film is slow, funny, or heavy. Reviews do. Grounding each recommendation in review text means the agent can explain itself, and you can judge whether the reasoning fits your taste. Every answer comes with an expandable list of the reviews it used, so you can check the reasoning yourself.

Quick start

git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git
cd YOUR-REPO
pip install streamlit sentence-transformers numpy requests groq

# Add your keys to .streamlit/secrets.toml
# (or set them as environment variables):
#   GROQ_API_KEY = "your-key"
#   OMDB_API_KEY = "your-key"

streamlit run app.py   # use your script's filename

The app expects review_embeddings.npy and review_data.pkl in the project folder.
